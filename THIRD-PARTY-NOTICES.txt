CodeBrix.YamlParse is a fully managed .NET library for reading, parsing,
emitting, and serializing YAML. It is a faithful port of the YamlDotNet
library (version 18.1.0) into the CodeBrix.YamlParse.* namespace, targeting
.NET 10.

Unlike most CodeBrix libraries, CodeBrix.YamlParse DOES incorporate
third-party source code: the entire library is derived from YamlDotNet, whose
own YAML scanner/parser/emitter is in turn derived from the libyaml C library.
Both upstream projects are distributed under the MIT License, which is
compatible with this project's MIT License. Their copyright notices and
license texts are reproduced below, as the MIT License requires.

Authors:    Antoine Aubry and contributors

Scope of incorporation:
  Substantially all of the YamlDotNet 18.1.0 library source (the "YamlDotNet"
  project / NuGet package) was ported into this repository under
  src/CodeBrix.YamlParse/, preserving each upstream file's original MIT license
  header verbatim. The ported areas are:
    - CodeBrix.YamlParse            (root reflection / helper utilities)
    - CodeBrix.YamlParse.Core       (scanner, parser, emitter, events, tokens)
    - CodeBrix.YamlParse.Helpers
    - CodeBrix.YamlParse.RepresentationModel (YamlStream / YamlDocument / nodes)
    - CodeBrix.YamlParse.Serialization      (Serializer/Deserializer + builders,
                                             converters, naming conventions,
                                             node (de)serializers, type
                                             inspectors/resolvers, schemas, etc.)

Modifications made during the port (per CodeBrix family conventions):
  - Namespace rename: every `YamlDotNet[.X.Y...]` namespace became
    `CodeBrix.YamlParse[.X.Y...]`; each ported file's namespace line carries a
    `//was previously: <upstream-namespace>;` provenance comment.
  - Block-scoped namespaces were converted to file-scoped namespaces.
  - The library now targets net10.0 only (upstream multi-targeted
    net10.0;net8.0;netstandard2.0;netstandard2.1;net47). The upstream
    framework-selection `#if` directives were preserved rather than stripped;
    on net10.0 the compiler selects the modern branches, so the legacy
    netstandard / .NET Framework branches are inert dead code retained for
    auditability.
  - Strong-name signing was dropped. Upstream's
    YamlDotNet/Properties/CustomAssemblyInfo.cs (and AssemblyInfo.template),
    which carried strong-name InternalsVisibleTo and assembly attributes, were
    NOT ported; this repository uses the CodeBrix-standard
    src/CodeBrix.YamlParse/InternalsVisibleTo.cs granting internals access to
    CodeBrix.YamlParse.Tests (no public key).
  - The upstream `Nullable` polyfill NuGet PackageReference was dropped; net10
    provides the nullable-annotation attributes in the BCL.
  - The upstream YamlDotNet.Analyzers.StaticGenerator Roslyn source generator
    (a separate project that emits AOT-friendly static serialization contexts)
    was NOT ported in this iteration. The StaticSerializerBuilder /
    StaticDeserializerBuilder API surface is present, but the compile-time
    generator that produces the static type contexts is deferred to a future
    iteration.
  - A small number of nullable-reference-type flow warnings (CS8602/CS8604)
    that upstream suppresses via <NoWarn> were instead resolved at the source
    with behavior-preserving null-handling so this repository builds warning-free
    without project-level warning suppression.
